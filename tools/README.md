# ابزارهای جمع‌آوری اطلاعات (فقط‌خواندنی)

این پوشه برای آماده‌سازی اتصال برنامه به ایزابل (Issabel) و میکروتیک است. هیچ‌کدام از ابزارها چیزی را تغییر نمی‌دهند.

## ۱. اسکریپت PBX — `collect_pbx_info.sh`

روی سرور ایزابل (با کاربر root) اجرا می‌شود و فقط دستورهای نمایشی `asterisk -rx` را اجرا می‌کند:

- نسخهٔ Asterisk/Issabel و اینکه درایور SIP از نوع `chan_sip` است یا `PJSIP`
- ظاهر جدول peerها/contactها و تعداد داخلی‌های آنلاین و آفلاین
- User-Agent تلفن‌ها (Yealink و Htek)؛ بعضی firmwareها MAC را هم داخل آن می‌گذارند
- تنظیمات AMI (بدون رمز) و اینکه پورت 5038 باز است یا نه
- نام فایل‌های provisioning (اگر ماژول Endpoint Configurator ایزابل استفاده می‌شود، MACها اینجا دیده می‌شوند)

### اجرا

1. فایل را به سرور ایزابل منتقل کنید (مثلاً با WinSCP یا `scp tools/collect_pbx_info.sh root@192.168.228.2:/tmp/`).
2. روی سرور:

```bash
bash /tmp/collect_pbx_info.sh
```

3. خروجی در `/tmp/pbx_report_<تاریخ>.txt` ذخیره می‌شود. محتوایش را با `cat` ببینید و برای من بفرستید.

اگر هنگام اجرا خطای `bad interpreter` یا `^M` دیدید، پایان خط‌ها ویندوزی شده‌اند؛ این را بزنید و دوباره اجرا کنید:

```bash
sed -i 's/\r$//' /tmp/collect_pbx_info.sh
```

### حریم خصوصی

- در حالت پیش‌فرض، آخرین بخش IPهای خصوصی به `x` و سه بایت آخر MACها به `xx` تبدیل می‌شود؛ شمارهٔ firmware دست‌نخورده می‌ماند.
- هر خطی که شبیه رمز باشد حذف می‌شود و فایل‌های تنظیمات (`manager.conf`، `amportal.conf` و مانند آن‌ها) اصلاً خوانده نمی‌شوند.
- گزینه‌ها: `MASK=0` (بدون پنهان‌سازی)، `FULL=1` (جدول کامل داخلی‌ها)، `MAX_PEERS=60`، `SAMPLE_PER_VENDOR=2`، `OUT=/مسیر/فایل.txt`.

## ۲. میکروتیک — `mikrotik_commands.txt`

دستورها را در WinBox → New Terminal (یا SSH) یکی‌یکی paste کنید. همه فقط چاپ می‌کنند. دو دستور آخر را بعد از جایگزین کردن subnet تلفن‌ها اجرا کنید و فقط حدود ۱۵ خط اول را بفرستید.

## بعد از این

با خروجی‌ها، تحلیل‌گر داده‌های ایزابل و خواندن lease/ARP میکروتیک را روی فرمت واقعی‌شان می‌نویسم و تست می‌کنم.

# سامانه داخلی‌های هتل

## اجرا

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
py -3 app.py
```

سپس به `http://127.0.0.1:5000` بروید.

حساب اولیه مدیریت: `admin` / `admin123` — در اولین ورود، تغییر رمز اجباری است؛ اگر حسابی هنوز رمز پیش‌فرض داشته باشد، هنگام راه‌اندازی برنامه به‌طور خودکار برای آن تغییر رمز اجباری می‌شود.

ایمیل و موبایل سازمانی فقط به مدیران واردشده نمایش داده می‌شود. برای نمایش عمومی، متغیر محیطی `SHOW_CONTACT_PUBLICLY=1` را ست کنید.

## قالب ورود اطلاعات

در CSV یا Excel از ستون‌های زیر استفاده کنید:

`extension, title, person_name, department, location, notes, status`

شماره داخلی کلید یکتای داده‌هاست؛ هنگام ایمپورت، رکورد هم‌نام به‌روزرسانی می‌شود.

یک فایل آماده برای آزمودن ایمپورت در [sample_import.csv](sample_import.csv) وجود دارد.

## گزارش PDF

در پنل مدیریت، از بخش «خروجی گرفتن» می‌توانید گزارش PDF همه بخش‌ها یا یک بخش مشخص را دانلود کنید. گزارش همه بخش‌ها، هر بخش را در صفحه‌ای جدا با جدول داخلی‌های همان بخش نمایش می‌دهد. در ویندوز به‌طور پیش‌فرض از فونت `Tahoma` استفاده می‌شود؛ در صورت نیاز، مسیر یک فونت فارسی TTF را در متغیر محیطی `PDF_FONT_PATH` قرار دهید.

# سامانه داخلی‌های هتل

## اجرا

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
py -3 app.py
```

سپس به `http://127.0.0.1:5000` بروید.

حساب اولیه مدیریت: `admin` / `admin123` — در اولین ورود، تغییر رمز اجباری است؛ اگر حسابی هنوز رمز پیش‌فرض داشته باشد، هنگام راه‌اندازی برنامه به‌طور خودکار برای آن تغییر رمز اجباری می‌شود.

ایمیل و موبایل سازمانی فقط به مدیران واردشده نمایش داده می‌شود. برای نمایش عمومی، متغیر محیطی `SHOW_CONTACT_PUBLICLY=1` را ست کنید.

## قالب ورود اطلاعات

در CSV یا Excel از ستون‌های زیر استفاده کنید:

`extension, title, person_name, department, location, email, mobile, notes, status, present`

فقط `extension` و `title` الزامی‌اند. ستون‌های `email`، `mobile` و `present` اختیاری‌اند و فقط وقتی در فایل باشند اعمال می‌شوند؛ پس فایل‌های قدیمی بدون این ستون‌ها اطلاعات موجود را پاک نمی‌کنند. مقدار `present` را به‌صورت `حاضر` یا `خارج از شیفت` بنویسید. در Excel ستون `mobile` را از نوع Text بگذارید، وگرنه صفر ابتدای شماره حذف می‌شود.

خروجی CSV/Excel پنل مدیریت همین ستون‌ها را دارد، پس می‌شود خروجی را ویرایش کرد و دوباره ایمپورت کرد. خروجی عمومی، ایمیل و موبایل را فقط وقتی دارد که نمایش عمومی آن‌ها فعال باشد.

شماره داخلی کلید یکتای داده‌هاست؛ هنگام ایمپورت، رکورد هم‌نام به‌روزرسانی می‌شود.

یک فایل آماده برای آزمودن ایمپورت در [sample_import.csv](sample_import.csv) وجود دارد. این فایل سه رکورد آزمایشی با شماره‌های ۹۹۰۱ تا ۹۹۰۳ و بخش «نمونه» می‌سازد تا با داده‌های واقعی قاطی نشود؛ بعد از تست، آن‌ها را از پنل حذف کنید.

## گزارش PDF

در پنل مدیریت، از بخش «خروجی گرفتن» می‌توانید گزارش PDF همه بخش‌ها یا یک بخش مشخص را دانلود کنید. گزارش همه بخش‌ها، هر بخش را در صفحه‌ای جدا با جدول داخلی‌های همان بخش نمایش می‌دهد. فونت به این ترتیب پیدا می‌شود: مسیر `PDF_FONT_PATH` (اگر ست شده)، هر فایل `.ttf` داخل پوشهٔ `fonts` کنار `app.py`، `Tahoma` در ویندوز، و در لینوکس به‌ترتیب Vazirmatn، Noto Naskh Arabic و DejaVu Sans. اگر هیچ‌کدام پیدا نشود، پیام خطای واضح نمایش داده می‌شود. برای بهترین ظاهر، فایل `Vazirmatn-Regular.ttf` را در پوشهٔ `fonts` بگذارید.
